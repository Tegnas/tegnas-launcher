Eigene Welten.

Tegnas Launcher ist ein unabhängiger Desktop-Launcher für Minecraft: Java Edition. Er soll Installation, Instanzen, Mods, Ressourcenpakete, Shader, Skins und den Start des Spiels in einer übersichtlichen Oberfläche zusammenführen.

Microsoft Login

Anmeldung über den offiziellen Microsoft-OAuth-Flow. Microsoft-Passwörter werden vom Tegnas Launcher nicht erfasst oder gespeichert.

Minecraft Java

Der Launcher ist für Nutzer vorgesehen, die Minecraft: Java Edition rechtmäßig besitzen und ihr eigenes Microsoft-/Minecraft-Konto verwenden.

Desktop Client

Eigenständige Windows-Desktop-Anwendung mit eigener Microsoft Entra Application ID.

Über das Projekt

Tegnas Launcher befindet sich in Entwicklung. Für die Kontoanmeldung verwendet die Anwendung Microsoft OAuth, Xbox Live/XSTS und – nach entsprechender Freigabe – Minecraft Services. Es werden keine Zugangsdaten anderer Launcher verwendet oder nachgeahmt.

Rechtlicher Hinweis

Tegnas Launcher ist kein offizielles Minecraft-Produkt. Das Projekt ist nicht von Mojang oder Microsoft genehmigt und steht nicht mit Mojang oder Microsoft in Verbindung. Minecraft ist eine Marke von Microsoft/Mojang.
