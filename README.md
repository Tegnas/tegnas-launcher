# Tegnas Launcher Website

Kleine öffentliche Projektseite für Tegnas Launcher.

## GitHub Pages
1. Neues öffentliches Repository `tegnas-launcher` erstellen.
2. `index.html` in die oberste Ebene hochladen und committen.
3. Settings → Pages → Deploy from a branch.
4. Branch `main`, Ordner `/ (root)` wählen und speichern.
